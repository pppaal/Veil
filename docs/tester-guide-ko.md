# VEIL 베타 테스터 가이드

이 문서는 VEIL Private Beta 에 초대받은 친구/지인을 위한 안내입니다.
"버그 신고는 어디로?", "안전한가?", "내 메시지 어디 가나?" 같은 질문에
한 번에 답하려고 만들었어요.

## 1. 사전 준비

- 모바일 브라우저 (Chrome, Safari) 또는 데스크톱 브라우저
- 운영자가 알려준 데모 URL (예: `https://veil-beta.example.com/demo`)
- (선택) PWA 로 홈 화면에 추가 → 알림창처럼 띄우려면

## 2. 첫 사용

1. 데모 URL 접속
2. "PRIVATE BETA" 빨간 배너 확인 → 닫지 말고 한번 읽어주세요
3. **핸들** 입력해서 "새 핸들로 시작"
   - 핸들은 한 번 정하면 못 바꿉니다
   - 소문자/숫자/_ 만 가능
4. 친구한테 본인 핸들 (예: `@alice`) 알려주기
5. "새 대화" 누르고 친구 핸들 입력 → 대화 시작

## 3. 꼭 알아둘 것 (중요)

### 백업 없음, 복구 없음

- 비밀번호 재설정 같은 거 **없습니다**
- 브라우저 캐시 지우면 → 메시지 + 핸들 둘 다 영구 손실
- 다른 기기로 옮기려면 **이 기기에서 직접** 이전: 메뉴 → "다른 기기로 이전".
  핸들만 새 기기로 옮겨지고 (키는 새 기기에서 새로 만들어요), 지난 대화
  내용은 옮겨지지 않아요. 승인하면 이 기기는 로그아웃되고 다시 못 씁니다.

이건 버그가 아니라 **설계**입니다. 서버에 키가 없어서 우리가 복구해줄
수가 없어요. 카톡/텔레그램이랑 다른 점.

### 서버는 메시지 내용을 못 봅니다

- 메시지 본문은 운영자가 못 봅니다
- DB 를 열면 메시지는 `ciphertext` (의미 없는 base64) 지만, 핸들·연락처·대화
  멤버·통화 기록·그룹 이름은 보입니다
  ([서버 데이터 목록](server-data-inventory.md))
- 사진·파일·음성 첨부도 보내기 전에 기기에서 암호화합니다

### 외부 크립토 감사 미완료

- 종단간 암호화는 동작하지만 외부 보안 감사가 아직 안 끝났어요
- 베타 = "기능 동작 확인" 단계. 진지한 비밀은 정식 출시까지 보내지
  말아주세요

## 4. 자주 마주칠 상황

### "🔒 복호화 실패" 나 "🔒 보안 키 변경 — 확인 필요" 가 떠요

- 정상 동작이 아니에요. 키 교체로는 생기지 않고, 앱이 자동으로 고쳐주지도
  않습니다.
- "보안 키 변경" 배너: 상대가 기기를 바꿨을 수도, 누군가 대화를 가로채려는
  것일 수도 있어요. 대화의 **안전 번호**를 직접 만나거나 전화로 상대와
  비교한 뒤에만 수락하세요. 상대가 모르는 변경이면 "상대 키 아님" 으로
  거절하세요.
- 배너가 떠 있어도 대화는 멈추지 않아요: 보내는 메시지는 이 대화가 쓰던
  키로 계속 가고, 새 키에서 온 메시지만 확인할 때까지 잠긴 채로 있어요.
- "복호화 실패" 가 반복되면: 키·캐시를 지우거나 재가입하지 마세요. 지우면
  그 핸들로 다시 못 들어오고 대화가 전부 사라지며, 새 핸들끼리는 처음부터
  다시 신뢰해야 해요.
- 버그 또는 보안 문제일 수 있으니 운영자에게 신고하세요: 언제부터, 몇 개,
  안전 번호가 일치했는지. 메시지 본문과 핸들은 빼고 보내세요 (5장).

### "⚠️ 같은 이름, 다른 계정" 이나 "⚠️ VEIL이 발급하지 않는 이름" 이 떠요

- "같은 이름, 다른 계정": 전에 대화한 핸들과 같은 이름인데 계정이
  달라요. 그 사람인 척하는 누군가일 수 있어요.
- "VEIL이 발급하지 않는 이름": 보이지 않는 문자, 다른 문자 체계의 글자,
  대문자, 공백이 들어간 이름이에요. 어떤 계정도 이런 이름을 가질 수 없어요.
- 어느 쪽이든 이 대화와 계속하기로 확인하기 전까지는 아무것도 열거나
  보내지 않아요. 상대에게 다른 경로로 확인한 뒤에만 계속하세요.

### 새 메시지가 안 와요

- 우상단에 "연결됨" 인지 확인
- "연결 끊김" 이면 자동 재연결까지 5초
- 메뉴 → "연결 상태" 로 WebSocket 인지 폴링인지 확인

### 폰을 바꿨어요

기존 기기가 아직 있으면 직접 이전할 수 있어요:
1. 기존 기기: 메뉴 → "다른 기기로 이전" 을 누르면 코드가 나와요.
2. 새 기기: "기존 기기에서 이전" → 코드를 붙여넣기.
3. 두 화면에 나온 지문을 한 묶음씩 비교한 뒤, 5분 안에 기존 기기에서
   승인하세요.
4. 기존 기기는 로그아웃되고 다시 못 쓰며, 지난 대화 내용은 옮겨지지
   않아요. 대화 상대에게는 새 키 알림이 뜰 수 있으니 안전 번호를 다시
   비교하세요.

기존 기기를 이미 잃어버렸거나 지웠다면 되돌릴 방법이 없어요: 새 핸들로
가입하세요.

### 친구가 차단되거나 나를 차단한 것 같아요

- 차단된 사용자는 "그 핸들 없습니다" 처럼 보입니다
  (블록 상태를 노출하지 않는 게 보안 원칙)
- 운영자한테 "왜 안 보여요?" 물어도 운영자도 모릅니다 (정상)

## 5. 버그 신고

베타 중 발견한 버그는 운영자한테 직접:
- 어디서 (URL, 화면)
- 무엇을 했는지 (단계 1, 2, 3)
- 어떻게 됐는지 (기대 vs 실제)
- 가능하면 스크린샷

⚠️ **메시지 본문이나 핸들은 보내지 마세요.** 운영자도 그걸 보면 안 됩니다.
"@bob 한테 메시지 보냈는데 빨간 X 떠요" 정도면 충분해요.

## 6. 베타 종료 시

베타 종료일은 운영자가 미리 공지합니다 (보통 4-8주). 종료 시:
- 모든 메시지/계정/키 영구 삭제
- 정식 출시는 별도 가입 (기존 핸들 재사용 보장 없음)

## 7. 신고

- 스팸/괴롭힘: 운영자 (`abuse@veil.example`) 한테 가해자 핸들 + 사건
  일시 보고
- 운영자는 메시지 본문은 못 봅니다. 메타데이터 (누가 누구한테 언제)
  로만 판단해요
- 처리 정책: `docs/ops/abuse-triage.md`

## 8. 자주 묻는 질문

**Q. 안전한가요?**
A. X3DH(X25519·Ed25519) 키 합의 + Double Ratchet + AES-256-GCM 입니다
   (docs/crypto-envelope-spec.md). 다만 외부 크립토 감사 전이라 베타 단계.
   "기능 확인" 용으로만.

**Q. 텔레그램/카톡 대체할 수 있어요?**
A. 베타 단계에선 안 됩니다 — 통화, 푸시 알림이 부분 구현. 정식
   출시 시 1:1 메시지+그룹+첨부+통화+푸시 모두 지원 예정.

**Q. 내 데이터 어디 있어요?**
A. 메시지 본문 키는 **이 브라우저** 에만 있습니다. 서버에는 ciphertext +
   메타데이터 (핸들, 가입 시각, 메시지 시각). EU 거주자는 GDPR 데이터
   주체 권리 청구 가능 (`docs/ops/data-subject-request.md`).

**Q. 운영자가 내 메시지 볼 수 있어요?**
A. 못 봅니다. 베타라서 코드 베이스 본인이 직접 확인 가능 (오픈소스):
   메시지 본문 복호화 코드는 클라이언트에만 있습니다.

**Q. 이 베타 사이트 24/7 살아있나요?**
A. 아니요. 운영자 노트북이 켜져있을 때만 (Cloudflare Tunnel 구조).
   접속 안 되면 운영자한테 핑.
